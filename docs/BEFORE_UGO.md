# Before U Go

Opens from Home. It never invents a destination.

If there is no context: **where are you going?** plus the Always list.

If the user names a destination: Always, For this trip (local keyword pack),
and Blugo suggests (local weather stub + rules). Items are checkable and stored.

Add something → Always or This trip. See [MEMORY.md](./MEMORY.md) for what is
local vs not built yet.
